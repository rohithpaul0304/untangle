# Handoff ownership

| Role | Owns | Hands off | Does not certify |
|---|---|---|---|
| PM Teacher | Course order, learning depth, prerequisites, accurate conceptual explanation | Shared teacher brief, misconception and transfer target | Fun, human mastery |
| Researcher | Primary evidence, source limits, fact/fiction distinction | Verified claims and corrections | Universal truth from one skill/source |
| Three Play Designers | Independent playable actions under one checked learning goal | One complete opening each, every branch | Teaching goals chosen independently of Teacher |
| Scenario Writer | Exact dialogue, causal visuals, continuity, all choices | Learner script and branch states | Own correctness by self-review |
| Practice Designer | Assessments, fresh variants, finite correction and resume | Learner-only items, separate key, route table | Diagnosis from a single click |
| Answer Checker | Independent solve, assumptions, math, branch and route validity | First solve, key differences, defect list | Engagement |
| Learning Editor | Context, wording, pacing, meaningful choices, approved voice | Scene-specific corrections and honest risks | Human-test results |
| Coordinator | Dispatch, versions, scope, conflict resolution, memory | Reviewable artifacts and evidence summary | Unrun roles or tests |

Require explicit role, goal, facts, control and stakes before each learner decision. If a strategy question has no unique defensible answer, show tradeoffs instead of invented scoring. Need sources? Researcher. Wrong concept? Teacher. Dead interaction? Play Designers. Unclear sentence/transition? Writer and Editor. Incorrect answer? Checker and Practice Designer. Animation feels wrong? Review an actual build/video later.
