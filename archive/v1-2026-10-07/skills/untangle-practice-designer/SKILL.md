# Practice Designer

Read the teacher brief, selected script when available, project STORY-WRITING.md and content-team feedback history. Practice may assess only taught material or facts explicitly supplied in the question. Read [contract.md](references/contract.md).

For each learning goal, produce a short closing check, a genuinely changed transfer problem and targeted correction. A new name with identical numbers is not fresh transfer. Vary the relevant condition: window, constraint, cause, data source or recoverability. Make wrong alternatives plausible and tied to specific reasoning errors; don't give away the answer through length or moral tone.

## Required separation

Save `practice-learner.md` with prompts, evidence and options only. Save `practice-key.md` separately with worked solutions, alternative explanations, tags and feedback. Never send the key or response feedback to the Answer Checker before its independent solve is saved. Keep exact item IDs and versions consistent.

Classify each item as objective, assumption-conditional or unscored judgment. For a conditional best answer, show the goal and assumptions before submission. Never use a hidden invented payoff to mark the learner wrong. Initial guesses can be unscored exploration.

## Correction routes

Incorrect original → explicit verdict plus specific causal feedback → a fresh item targeting the likely error → supported retry or return to chapter. If another error occurs, show a worked example and offer pause or continue with review needed. No chapter restart or endless loop. Correct answers get an explanation too.

A selected distractor suggests a possible misconception; it does not establish motivation or a durable learner diagnosis. Fresh answers and supported retries must be recorded separately. A correct click is not mastery. Review failures are teaching events, not punitive lost progress.

## Runtime boundary

The AI may select among checked variants and suggest a targeted explanation. Reviewed answer keys and deterministic rules decide objective correctness. Uncertain free-text interpretation must not silently fail the learner or unlock a chapter; use a clarifying check or mark review needed. New generated scored variants need checking before delivery. This is an authoring contract, not an implemented Convex service.

Return learner items, key, finite route table and a minimal progress record. Independent checker findings go back to you for revision. Do not claim human learning outcomes from passing logic tests.
