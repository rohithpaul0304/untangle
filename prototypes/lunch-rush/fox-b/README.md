# B fox — gesture preview

Open ../fox-b.html. The approved soft B fox stays compact at the bottom, below the example content, at 125–150px wide.

## Current motion

Version 3 replaces the previous whole-image bounce with sequential drawn poses. Each gesture sheet has four columns and three rows. The canvas displays one cell at a time: paws and arms articulate, facial expressions change, and the fox returns to a settled pose. There are no CSS transforms that shake the character.

Wave hello raises and waves a paw. Explain opens both palms while the mouth changes. Think moves a paw to the chin and glances upward. React raises both palms with wide eyes. Celebrate raises both fists, pumps them, and laughs. Each gesture plays once on selection or replay. Pause and resume retain their place. Reduced motion displays the settled final frame.

This is a twelve-pose gesture prototype, not a continuously rigged animation. Timing and small variations between generated frames still need polish before matching the smoothness of the Duolingo reference. The underlying character is preserved, with naturally connected shoulders and both paws visible.

Assets were made with ChatGPT’s built-in image tool using the approved waiting-v2.png identity reference and the celebration sheet as the consistent grid reference. Older images are retained. No external video service, Figma, audio, or backend is used.
