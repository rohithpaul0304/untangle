# Coin Camp — guided prisoner’s dilemma

Serve this directory on port 4175. The historical folder name is retained to keep the preview URL working.

`index.html` contains the scene and animated vector fox; `story.js` guides four outcomes of a coin-sharing game, a short explanation, and three cigarette-advertising case beats. Each person starts with 3 coins. Sharing gives 6 to the recipient; keeping retains 3. Outcomes are 6/6, 9/0, 0/9, 3/3.

The first choice in each rival setup is free. The second is explicitly guided to explore the other action. No scores or correct-answer labels. Each trial resets coins and plays day-to-night with a visible count. Reduced motion is supported. Restart returns to the beginning. Progress is not saved; there is no backend, account, or AI connection.

`model.js` and `fox-guide.png` are retained historical assets, unused by this version. The second real-world example is pending the user's input and has not been invented.
